# S2 — Presets / Display-Types Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a per-screen `preset` enum (14 grey wireframe skeletons + `custom`) with a right-click "Créer" menu on the empty board and a "Modifier le layout" submenu on existing screens — without breaking today's HTML-content screens.

**Architecture:** `preset` is a new optional field on `Screen`; absent ⇒ `custom` ⇒ today's behavior (backward-compatible). `renderScreen` swaps only the **body**: `custom` renders `content` (today), other presets render a grey skeleton from a `PRESETS` registry. A new reusable context-menu component powers both the create and modify submenus (and S3 later). Created screens live in runtime state and persist only via Copy Init (S1 will own real text persistence).

**Tech Stack:** TypeScript, tsup, vitest+jsdom, CSS (`fb-` prefix).

---

## Hard constraints
- Screens without `preset` (all existing boards) render **exactly as today**.
- The screen **header (title) and notes footer are unchanged** — only the body differs.
- `custom` keeps `screenData.content` (the HTML). Switching to a preset **hides** content but keeps it in data (non-destructive, reversible).
- No localStorage model change (persistence via Copy Init; real persistence is S1).
- Behavior preserved → the existing test suite stays green; new features get new tests.

## Task 4: Render body by preset — `src/render/screen.ts`

**Files:** Modify `src/render/screen.ts`; test in `flowboard.test.js` (or interactions).

- [ ] **Test first**: a `Screen` with `preset: 'form'` → its element body has class `fb-skel-form` and does NOT inject `content`; a `custom`/no-preset screen → body `innerHTML === content`.
- [ ] Implement: in `renderScreen`, replace the body block with:
```ts
var body = document.createElement('div');
body.className = 'fb-screen-body';
var preset = screenData.preset || 'custom';
if (isCustomPreset(preset)) {
  body.innerHTML = screenData.content || '';
} else {
  body.classList.add('fb-skeleton', 'fb-skel-' + preset);
  body.innerHTML = skeletonHtml(preset);
}
el.appendChild(body);
```
- [ ] `npm test` → green. Commit `feat: render screen body by preset`.
